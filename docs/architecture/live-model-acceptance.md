# Live model acceptance

`ops/acceptance-real-model.py` is an explicit operator action (`TEAMIE_REAL_MODEL_ACCEPTANCE=1`). CI uses protocol fixtures, disposable databases and the real isolated runner; it does not call a model provider.

Use the existing administrator credentials through `TEAMIE_ADMIN_EMAIL`/`TEAMIE_ADMIN_PASSWORD` in a private environment. Reuse the saved gateway configuration by default. Set all three `TEAMIE_REAL_PROVIDER_BASE_URL`, `TEAMIE_REAL_PROVIDER_API_KEY`, `TEAMIE_REAL_PROVIDER_MODEL` only to intentionally replace that model. `TEAMIE_REAL_WEB_SEARCH_API_KEY` can independently configure web search; saved model secrets and the context window are preserved. Secrets must never be committed or supplied in command-line arguments.

Private SSE verification also requires `TEAMIE_INTERNAL_GATEWAY_URL` and `GATEWAY_RUNTIME_TOKEN` through the private container network or an operator tunnel. The public edge continues to reject internal routes. The harness obtains the opaque config ID from a private unary response, then pins the stream to it; it does not implement a second hash algorithm. A configuration change between probes fails the group; restart the group against the intended saved configuration.

`TEAMIE_REAL_EVIDENCE_COMMAND` is a JSON argv array, defaulting to `["bash","ops/acceptance-evidence.sh"]` resolved relative to the script. On the production host, that wrapper uses the current release's Compose configuration and a shared deployment lock. An operator can supply an explicit argv wrapper for remote execution; no shell interpolation is performed by Python. Runtime's `runtimectl acceptance --agent ID --message ID` opens its own database read-only without migration. Sandbox's `sandboxctl task` projects its own durable receipt; `sandboxctl isolation --nonce ID` creates and removes a disposable, credential-free probe container and two temporary directories under its workspace root. It verifies the actual Docker isolation configuration and executes fixed isolation checks. Execution children receive no operator/service credentials.

The report follows only the triggering message's runs and their durable child inputs. IM sends, denied reads, uploads, successful Sandbox tasks, web tools and schedule firing must match their receipts. A foreground WAKE response or WEB text alone fails. Model output, commands, tool arguments, file/message bodies and provider details never enter the report. These commands are not routed to browsers, including Agent owners and administrators.

The harness creates an invited ordinary peer, a workspace and a disposable Agent. The peer joins the workspace; a private group includes the administrator and peer, excluding the Agent. The Agent is deleted in cleanup, including after failure. Fixture account/workspace/message rows remain auditable; do not delete unrelated production records. Successful checks write a new mode-0600 `real-acceptance-<nonce>.json` under `TEAMIE_REAL_EVIDENCE_DIR` (default `.runtime`). Exit 0 requires all configured scenarios plus private unary/SSE and web acceptance; missing private credentials or disabled web returns 2 with explicit unverified items. Missing internal evidence fails instead of claiming full acceptance. `TEAMIE_REAL_MODEL_TIMEOUT` limits the harness's observation wait, not Agent execution; it has no imposed upper cap and does not cancel the Agent's turn.
